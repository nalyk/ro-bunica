# Securitate

Dacă găsești o vulnerabilitate (un exploit în joc, o cale de a fura sau duplica creaturi, o cheie sau un secret expus în repository), nu deschide un issue public. Raportează-o privat prin [GitHub Security Advisories](https://github.com/nalyk/ro-bunica/security/advisories/new).

Cheile API și alte secrete nu intră în git: `.env.cloud` e ignorat, iar CI-ul folosește doar secretele GitHub.
